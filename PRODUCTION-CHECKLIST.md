Record backup timing, maximum tolerable response loss, 30-day archive expiry, 35-day journal expiry, and how every withdrawal is independently copied. 9. **Engineering after your approval:** deploy the reviewed code to Production with collection still disabled; test both activities at the public URL. When separately authorized, use production-only `PC_COLLECTION_MODE=enabled` and `PC_REAL_COLLECTION_APPROVAL=reviewed-18plus-five-years`, redeploy and verify the actual public consent and a test submission/withdrawal.
10. **You + operator:** monitor the first event, project health, quotas, backup copies, independent journal and expiry. To stop new sharing, disable collection and redeploy while preserving withdrawal access. A rollback must not remove withdrawal APIs or abandon retention.
